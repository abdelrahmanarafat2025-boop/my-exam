# MyExam — موقع امتحانات شخصي

## المتطلبات
- VS Code
- متصفح حديث مثل Chrome أو Edge
- لا تحتاج إلى تثبيت مكتبات أو تشغيل خادم.

## التشغيل
1. فك ضغط ملف `MyExam.zip`.
2. افتح VS Code ثم اختر **File → Open Folder** وحدد مجلد `MyExam`.
3. افتح `index.html`.
4. شغّل الملف في المتصفح. يُفضّل تثبيت إضافة **Live Server** من قسم Extensions في VS Code، ثم الضغط بزر الفأرة الأيمن على `index.html` واختيار **Open with Live Server**.
5. اضغط «إنشاء امتحان»، واكتب الاسم والمادة، ثم احفظ.
6. من صفحة إدارة الامتحان اضغط «إضافة سؤال»، واختر النوع، واكتب السؤال والدرجة ثم احفظ.
7. اضغط «ابدأ الامتحان»، وأجب ثم سلّم لرؤية النتيجة ومراجعة الإجابات.

## أنواع الأسئلة
- اختيار من متعدد: تصحيح تلقائي.
- مقالي: تُكتب إجابة نموذجية، ثم تُقيّم إجابتك يدويًا بعد التسليم.

## أين تُحفظ البيانات؟
تُحفظ الامتحانات والأسئلة والنتائج داخل `localStorage` في المتصفح الحالي. البيانات لا تنتقل تلقائيًا بين المتصفحات أو الأجهزة. مسح بيانات الموقع أو المتصفح قد يحذفها؛ لذلك احتفظ بنسخة احتياطية عند إضافة ميزة التصدير.

## الملفات
- `index.html`: هيكل الصفحات والنماذج.
- `style.css`: التصميم الداكن والمتجاوب.
- `script.js`: إنشاء الامتحانات والأسئلة، تشغيل المحاولة، التصحيح، النتائج والتخزين المحلي.

## ملاحظات
هذه نسخة أولى تعمل محليًا ولا تتطلب حساب مستخدم. لا تضع بيانات سرية فيها؛ فالبيانات مخزنة في متصفح جهازك.
